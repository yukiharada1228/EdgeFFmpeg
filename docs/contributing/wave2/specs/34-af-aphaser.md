## Capability specification
- Upstream source: upstream/ffmpeg/libavfilter/af_aphaser.c (+ generate_wave_table.c WAVE_TRI)
- Scope: Options in_gain, out_gain, delay, decay and speed with native ranges; type=triangular|t, which is the default. type=sinusoidal|s is refused: `aphaser type sinusoidal requires unimplemented libm arithmetic`. formats() ['dbl','dblp','flt','fltp','s32','s32p','s16','s16p'] in source order. The packed and planar kernels compute identically. constraint(): delay_buffer_length=(int)(delay*0.001*sr+0.5) must be > 0, or native fails with 'delay is too small'. modulation_buffer_length=(int)(sr/speed+0.5) must be >= 1. The integer kernels convert v*out_gain to int16/int32 by C truncation, which is undefined out of range. So parse() refuses in_gain/(1-decay) > 1/out_gain, native's 'out_gain may cause clipping' condition, which bounds every output by the input peak. The agent proves that this bound survives double rounding at the s32 extremes, or tightens it. Stream step: a delay ring of length x channels doubles, an int32 triangle table (min 1, max length, phase pi/2, +-0.5 rounding then truncation), delay_pos and modulation_pos. Count unchanged. enable= is refused.
