## Capability specification
- Upstream source: upstream/ffmpeg/libavformat/sol.c
- Scope: Demux-only. Probe: low 16 bits of RL32 are 0x0B8D/0x0C0D/0x0C8D and bytes 2-5 are "SOL\0" (head 4 bytes, confirm 6 bytes, precedence 100). Header: magic u16, tag, rate u16le, type u8, size u32 (ignored), plus one padding byte unless magic 0x0B8D (data at 13 or 14). Codec per sol_codec_id: type&1 -> sol_dpcm (refused); magic 0x0B8D -> pcm_u8 mono; type&4 -> pcm_s16le; else pcm_u8; stereo when type&16 and magic != 0x0B8D, av_channel_layout_default. Packets are 4096 bytes, so packetSpan = 4096/blockAlign (probe: 1024 for s16 stereo, 4096 for old u8); the CORRUPT flag is cleared, so short final packets are exact. Refused: DPCM, rate 0, trailing partial sample, input -ss>0 until probed. Data runs to EOF.
- Files you own: packages/containers/src/sol.ts, packages/containers/NOTICE-SOL, docs/contributing/sol-support.md, tests/unit/sol.test.ts, tests/differential/sol.test.ts, docs/contributing/wave2/fmt-sol.json
- Shared one-line registry edits you may make: packages/containers/src/registry.ts: +1 line `export {sol} from './sol.js';` at its alphabetical position (merge=union)
- Test strategy: Unit: three magics, header offsets 13/14, codec/channel table, DPCM refusal, bounded reads, abort. Differential tests synthesize inputs in the test and run .build/reference/ffmpeg at test time (read build-metadata.json, assert commit 946fcce0 and --disable-x86asm; never pin a binary sha or commit native digests). Batch native calls; one file should finish in ~3 min on 4 vCPUs. Cases: u8 mono (old and new magic), u8 stereo, s16le mono/stereo, at 8000/11025/22050 Hz, lengths around 4096-byte boundaries; outputs framecrc decode and -c copy, wav, raw, au; output -ss/-t; DPCM and rate-0 native statuses.
- Determinism notes: Byte copies and integer header arithmetic only; decoding uses the existing PCM codecs. Nothing is platform-dependent, so every comparison runs on darwin and linux. Native probes on the pinned macOS arm64 reference (1b86106f) confirmed the packet layout quoted in scope.
- Linux-gated float cases: none expected
- Registry notes (these override conflicting wording above): Follow docs/contributing/container-registry.md. Exact, non-overlapping magics use precedence 100. A refused native errno status uses the host value from os.constants.errno for native and the Linux value for EdgeFFmpeg (the wave-1 ircam lesson). Verified (wave2-select probe): s16 stereo at 22050 Hz gives 1024-sample packets and an unflagged short final packet, so no copy refusal is needed.
