## Capability specification
- Upstream source: upstream/ffmpeg/libavformat/sdsdec.c
- Scope: Demux only.
- Header F0 7E xx 01 with bit_depth 8..28; probe as native, including buf[20]==F7.
- The sample period is three 7-bit bytes; rate = period ? 1e9/period (integer) : 16000. Duration is ((size-21)/127)*size/4.
- Each 127-byte data packet (F0 7E ch 02 nn, 120 data bytes, checksum, F7) is unpacked by byte2/3/4_read into left-justified pcm_u32le: 60, 40 or 30 samples per packet. The checksum is ignored and F7 is checked.
- Packets are uniform within a stream, so the registry's per-format input packet span hook carries 60/40/30.
- Bad packet headers, a missing F7 or a truncated final block are validated up front with bounded reads and refused before output. Native's mid-stream demux error semantics are not mirrored.
- Files you own: packages/containers/src/sds.ts, packages/containers/NOTICE-SDS, docs/contributing/sds-support.md, tests/unit/sds.test.ts, tests/differential/sds.test.ts, docs/contributing/wave1/fmt-sds.json
- Shared one-line edits you may make: container format registry: +1 demux-only registration line (native probe; input packet span 60/40/30 samples); packages/containers/src/index.ts: +1 export line only if the recipe requires it
- Test strategy: Synthesized dumps: bit_depth {8,13,14,20,21,28} x periods (0, typical, extremes) x packet counts {0,1,7}, with random 7-bit payloads.
- Native vs Edge: copy framecrc (pcm_u32le rows of 60/40/30 samples), decode to s16le/WAV, -t/-frames:a.
- Error matrix: bad F07E, missing F7, truncated block, depth 7/29. Edge refuses; record native's exit status.
- Unit: the three unpackers and the rate formula.
- Determinism notes: Integer bit unpacking and integer rate division.
- Registry notes (these override any conflicting wording above): none
