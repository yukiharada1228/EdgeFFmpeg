## Capability specification
- Upstream source: upstream/ffmpeg/libavformat/epafdec.c, pcm.c
- Scope: Demux only.
- Magic 'fap ' requires word@8==1 (little-endian); ' paf' requires word@8==0 (big-endian). The probe also requires word@4==0 and non-zero words at 12 and 20, as native does.
- Codec 0 maps to s16le/s16be and codec 2 to s8. Codec 1 (24-bit) and anything else is refused, with native's INVALIDDATA status.
- Channels 1..512, rate > 0, data at 2048, default PCM packet span.
- Refuse partial trailing frames and truncated 2048-byte headers.
- Files you own: packages/containers/src/epaf.ts, packages/containers/NOTICE-EPAF, docs/contributing/epaf-support.md, tests/unit/epaf.test.ts, tests/differential/epaf.test.ts, docs/contributing/wave1/fmt-epaf.json

- Test strategy: Synthesized LE/BE files x codec {0,2} x channels {1,2,6} x rates {8000,44100,96000} x odd lengths, compared byte for byte with native through copy framecrc, WAV, AIFF and raw outputs, plus -ss/-t.
