# FLAC decode backend scope

`executeFlacDecode` requires a trusted precompiled libFLAC module. Production has no Native or Node fallback. PCM sample planes are signed/right-justified and shifted into the existing left-justified packed s32 PCM contract. One selected audio stream and one transactional output are supported. WAV/framecrc default to pcm_s16le, AIFF/AU to pcm_s16be, and explicit raw PCM formats select their corresponding codec. The actual Node launcher accepts the verified module through `--flac-wasm`.

Finite decoded frame limits and unknown-total nonempty inputs now work through a bounded counting prepass for PCM/WAV/AIFF/AU. Decoder passes run sequentially, release their real 16 MiB reservation, and never retain the whole decoded stream. Frame limits count decoded FLAC frames. Zero-frame and empty inputs produce empty muxed output. Native comparisons cover 162 prepass conditions and 342 AIFF/AU output conditions; these same 504 conditions also execute through public APIs on actual local R2/workerd. Fixture provenance is recorded in the adjacent corpora; reference generation is development-only.

Copy and decode share ordered, optional and negative stream-map selection with immutable policy snapshots and exact picture identities. An unmatched optional map can fall back to automatic selection. Explicit selected pictures and multiple decoded audio copies are rejected before output publication. The selector has a bounded 64-map/stream policy; advanced stream specifiers remain unimplemented.

Explicitly unfinished: multiple outputs/decoded duplicate maps; tag preservation (arbitrary tags require `-map_metadata -1`); chapter preservation (still rejected even when tags are stripped); selected attached-picture output; timestamp offsets/noncontiguous sample positions; AVIO error-policy equivalence and deferred read errors; seeking and input/output time ranges; filters, resampling/remixing; encoder time-base overrides; additional muxers. Unsupported options fail rather than being silently ignored. Retained readers preserve source identity, but providers must supply stable contents across prepass and output pass.

The pre-existing malformed corpus has **22 PCM differences, 31 completion differences, and 56 unsupported CLI-policy cases** against pinned Native. These changes do not fix or bypass those libFLAC policy differences, disable CRC checks, or certify full compatibility. MD5 checking is not enabled by default. Rollback tests for malformed inputs establish atomicity, not Native recovery parity.
